МОЯ ТРАЕКТОРИЯ — прототип

index.html — главная страница для GitHub Pages.
miniapp.html — тот же прототип с адресом, совместимым с мини-приложением.

Для публикации: загрузите оба HTML-файла в корень репозитория GitHub, затем включите Settings → Pages → Deploy from a branch → main → /(root).

Внимание: это демонстрационная версия. Прогресс сохраняется локально в браузере (localStorage); общей базы данных, авторизации и синхронизации между устройствами пока нет.
