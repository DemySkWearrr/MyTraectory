# Моя траектория

Два прежних курса 11 класса остаются в `index.html` и используют существующие аккаунты и таблицу `student_progress`. Для 10 класса добавлены семь групп, Python и Web по 36 занятий с краткой теорией и отдельными заданиями. Новому ученику назначаются оба курса. Проверка учителя хранится вместе с соответствующей версией ответа.

## Что вставить в Supabase

Начни с тестового проекта с копией схемы и вымышленными аккаунтами. Пакет дополняет существующую платформу и предполагает, что уже есть таблицы `profiles`, `student_progress` и функции `change-password` и `reset-student-password`. Схема старых данных и исходники этих функций отсутствуют в GitHub. Перед переносом сделай резервную копию и проверь, что действующие функции меняют признак временного пароля от имени сервера.

1. **SQL Editor → New query.** Вставь целиком `supabase/migrations/202611100001_grade_10_review_workflow.sql` и нажми **Run**. При ошибке вся миграция откатывается. Новые группы пустые. Списки учащихся не импортируются, существующие профили и прогресс 11 класса сохраняются. Если данные 10 класса уже есть в прежних таблицах, сначала согласуй перенос, чтобы не создать дубли аккаунтов.
2. **Edge Functions → Deploy a new function → Via Editor.** Укажи имя `create-students`, замени содержимое `index.ts` файлом `supabase/functions/create-students/index.ts` и нажми **Deploy function**. Оставь проверку JWT включённой. Supabase предоставляет серверный ключ функции автоматически. Для тестовой страницы на другом домене задай секрет `TRAECTORY_SITE_ORIGIN` равным её origin, например `http://localhost:8080` без завершающего слеша. Для действующего GitHub Pages используется `https://demyskwearrr.github.io`.
3. **Сайт.** В тестовой копии замени `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY` в `index.html` на значения тестового проекта. Держи `index.html`, `grade10.js` и `lessons-grade10.js` рядом. Серверные ключи и реальные временные пароли в файлы сайта и GitHub не добавляй.

Документация Supabase: [SQL Editor и функции базы](https://supabase.com/docs/guides/database/functions), [развёртывание Edge Function через Dashboard](https://supabase.com/docs/guides/functions/quickstart-dashboard), [авторизация Edge Functions](https://supabase.com/docs/guides/functions/auth).

## Проверка перед публикацией

1. Войди учителем. В блоке **10 класс → Создать ученика** создай два вымышленных аккаунта в разных группах. Для временного пароля используй случайную строку из 12–72 латинских символов, цифр и знаков. Передавай пароли лично.
2. Войди первым учеником, поменяй временный пароль и отправь решение первого урока Python. Статус станет **На проверке**.
3. Войди учителем, выбери группу, ученика и Python. Поставь 3, заполни комментарий и рекомендацию, выбери **Вернуть на доработку**.
4. У ученика нажми **Обновить проверки**, исправь ответ и отправь новую версию. Учителем зачти её с оценкой 5. Проверь, что в истории видны оба ответа и обе проверки, а прогресс стал **1 / 36**.
5. Проверь вторым учеником, что в истории нет чужой работы. Проверь, что ученику запрещены чтение чужой строки через API, прямая запись оценки и вызов функции создания аккаунта.
6. Войди существующим учеником 11 класса в тестовой копии. Проверь два курса, сохранение ответа, старый прогресс и учительскую ведомость.

Если всё прошло, загрузи пакет в отдельную ветку GitHub и открой черновик PR. Слияние и публикация требуют подтверждения. Старый ключ Google Sheets нужно отозвать или заменить в Apps Script, поскольку он уже был в опубликованной версии.

## Проверка старых правил доступа

На рабочей базе этот запрос только читает настройки. Он не выгружает имена, работы или оценки. Перед запуском убедись, что RLS включена для `profiles` и `student_progress`, а политики и ранее созданные RPC не раскрывают чужие ответы или роль.

```sql
select c.relname as table_name, c.relrowsecurity as rls_enabled
from pg_class c join pg_namespace n on n.oid = c.relnamespace
where n.nspname = 'public'
  and c.relname in ('profiles', 'student_progress', 'student_roster', 'student_lesson_reviews')
order by 1;

select tablename, policyname, roles, cmd, qual, with_check
from pg_policies
where schemaname = 'public'
  and tablename in ('profiles', 'student_progress', 'student_roster', 'student_lesson_reviews')
order by 1, 2;
```
